This API exposes parking stations from the Open Data Hub timeseries API (mobility.api.opendatahub.com) in a condensed custom format for VMS displays.

This API is considered an [R&D prototype](https://opendatahub.com/lifecycle-management/), and thus we cannot guarantee future availability nor stability.

If you intend to use this API for production deployments, please contact the Open Data Hub team help@opendatahub.com
